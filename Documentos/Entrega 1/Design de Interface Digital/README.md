# Design de Interface Digital — Entrega 1

**Projeto:** KFKA — Plataforma de Acompanhamento Escolar

Esta entrega apresenta os principais materiais de design desenvolvidos para a plataforma KFKA. Os arquivos foram organizados no Figma e podem ser acessados pelos links abaixo.

---

## 1. Guia de Estilo

[🔗 Visualizar no Figma](https://www.figma.com/proto/nclcEcJvr30eaI2GlxQRml/KFKA---Design?node-id=0-1&t=UoBmgJrRSMfRMY7a-1)

O Guia de Estilo reúne as definições visuais utilizadas como base para a construção da interface do sistema.

Entre os elementos definidos estão:

- Paleta de cores 
- Padrões tipográficos
- Estilos de botões
- Campos de formulário
- Identificação de usuário
- Tabelas e elementos de organização de dados

---

## 2. Home Page

[🔗 Visualizar no Figma](https://www.figma.com/proto/nclcEcJvr30eaI2GlxQRml/KFKA---Design?node-id=1-3&t=UoBmgJrRSMfRMY7a-1)

A Home Page representa a proposta visual da tela inicial da plataforma e aplica os padrões definidos no Guia de Estilo.

O desenvolvimento da interface considerou aspectos como:

- Distribuição e organização dos conteúdos
- Clareza na hierarquia das informações
- Facilidade de navegação
- Padronização dos elementos visuais
- Aplicação da identidade visual da KFKA

---

## 3. Mapa de Navegação

[🔗 Acessar o Mapa de Navegação]( LINK AQ )

O mapa de navegação apresenta a estrutura de acesso às páginas e funcionalidades da plataforma, organizando os caminhos disponíveis para cada tipo de usuário.

### Módulo Responsável

- Visualização do aluno vinculado
- Acompanhamentos
- Registro de ciência
- Histórico
- Geração de relatório em PDF

### Módulo Professor

- Minhas turmas
- Meus alunos
- Registros de acompanhamento
- Salvamento em rascunho
- Envio para revisão
- Consulta de ciência

### Módulo Administrador

- Gerenciamento de cadastros
- Revisão e publicação de acompanhamentos
- Configuração dos períodos bimestrais
- Consulta de relatórios
- Exportação de informações para Excel
